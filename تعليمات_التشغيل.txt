تعليمات نظام "البصيرة الرقمية" — النسخة الكاملة
====================================================

الملفات اللي بهذا المجلد:
--------------------------
1) app.html                        <- نسخة جاهزة تفتحينها مباشرة بالمتصفح (بدون شات أورا)
2) app_template.html               <- القالب (بايثون يقرأ منه، ما تفتحينه بنفسك)
3) app_agent.py                    <- محرك تحليل الطلاب (يستخدمه كل من الملفين تحت)
                                      يشتغل على Gemini، وبدون مفتاح يشتغل بالقواعد فقط
4) web_app.py                      <- **السيرفر الموحّد** للنشر أونلاين (الموقع + الشات + التقارير)
5) chat_server.py                  <- سيرفر شات محلي بس (بديل أبسط، بدون نشر أونلاين)
6) students_data_elementary.csv    <- بيانات ٣٠ طالب (تقدرين تعدلين فيها)
7) config.txt                      <- هنا تحطين مفتاح Gemini
8) requirements.txt                <- المكتبات المطلوبة (للنشر أونلاين)


خياران للاستخدام — اختاري وحد:
===================================

الخيار أ) تجربة سريعة محلية بدون نشر (الأسهل، بس بدون رابط عام):
-------------------------------------------------------------------
- افتحي app.html مباشرة بالمتصفح لعرض الداشبورد بدون الشات
- لتفعيل الشات محلياً: حطي مفتاحكم بـ config.txt، ثم:
    python3 -m pip install google-genai
    python3 chat_server.py
  اتركي Terminal شغّال، وافتحي app.html بمتصفح Chrome

الخيار ب) النشر أونلاين برابط حقيقي (المطلوب من الدكتور):
--------------------------------------------------------------
هذا يستخدم web_app.py وينشر على منصة استضافة مثل PythonAnywhere.
كل شي من المتصفح، بدون Terminal على جهازكم. الخطوات:

  ١. روحي pythonanywhere.com وسوّي حساب Beginner (مجاني)

  ٢. من تبويب "Files"، ارفعي هالملفات الخمسة بمجلد واحد:
     - web_app.py
     - app_agent.py
     - app_template.html
     - students_data_elementary.csv
     - requirements.txt

  ٣. من تبويب "Web"، اضغطي "Add a new web app" ← اختاري Flask ←
     اختاري نسخة بايثون (أي نسخة 3.x) ← وجّهي المسار لملف web_app.py

  ٤. من "Web" ← "Environment variables"، ضيفي متغيّر:
     GEMINI_API_KEY = مفتاحكم الحقيقي

  ٥. من تبويب "Consoles" ← افتحي "Bash console جديد"، واكتبي:
     pip3.10 install --user -r requirements.txt
     (غيّري الرقم 3.10 حسب النسخة المختارة بخطوة ٣)

  ٦. ارجعي لتبويب "Web" واضغطي الزر الأخضر "Reload"

  ٧. رابطكم جاهز فوق الصفحة، شكله:
     https://اسم_حسابكم.pythonanywhere.com


تشغيل تحليل الوكيل الكامل (Gemini) على البيانات:
--------------------------------------------------
الداشبورد يشتغل بالقواعد الحتمية بدون أي مفتاح. لو تبين "البصيرة
الذكية" مكتوبة فعلياً من النموذج اللغوي لكل طالب:

    python3 -m pip install google-genai
    (حطي مفتاحكم بملف config.txt)
    python3 app_agent.py

هذا يعيد توليد app.html بملاحظات Gemini لكل طالب. شغّليه من جديد
كل ما تتغير بيانات الـ CSV.

ملاحظة: كل الذكاء الاصطناعي بالمشروع على Google Gemini فقط —
نفس المفتاح (GEMINI_API_KEY) ونفس النموذج لكل من المحرك وأورا.
لتغيير النموذج: عدّلي LLM_MODEL بأول ملف app_agent.py، أو حطي
متغيّر بيئة اسمه GEMINI_MODEL.


الميزات الموجودة بالنظام:
----------------------------
- لوحة تنبيهات + قائمة طلاب (٣٠ طالب) + تحليل إحصائي
- ملف شخصي لكل طالب، مع إمكانية إضافة ملاحظة يدوية
  (لحالة لم ترصدها الكاميرا مستقبلاً)
- تبويب "التقارير": تقرير الوكيل الحالي، مع أزرار قبول/رفض/
  تعديل/طباعة — كلها تُحفظ فعلياً على السيرفر
- شات "أورا": وكيل ذكاء اصطناعي حقيقي (أدوات + قرار ذاتي)،
  نص وصوت، عربي وإنجليزي
