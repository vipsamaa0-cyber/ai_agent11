WHAT THIS PROJECT IS
--------------------
A dashboard for a school specialist (الأخصائية) that flags
elementary students who may need attention. It reads weekly data
(grades + behavioral notes) for 30 students, runs a real AI agent
over each one, and shows: alerts, student profiles, statistics,
a weekly report, and a chat assistant called "أورا" (Aura).

All AI in this project runs on GOOGLE GEMINI only.


BEFORE YOU START — is everything ready?
---------------------------------------
1. Your Gemini API key is already saved in the file  config.txt
2. The Python libraries are already installed inside the folder
   ".venv" in this same directory (google-genai + flask)

If the .venv folder is ever missing or you move this project to
another computer, recreate it with these two commands:

    cd "/Users/developer/Downloads/ia_agent 9"
    python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt

NOTE: on this Mac you cannot install the libraries system-wide
(Homebrew blocks it, error "externally-managed-environment").
That is why we use .venv. You do NOT need to "activate" it —
just write  ./.venv/bin/python  instead of  python3


----------------------------------------------------------------
OPTION A — FULL LOCAL RUN  (RECOMMENDED)
Dashboard + Aura chat + saving notes + report buttons
----------------------------------------------------------------

  Step 1) Open the Terminal app.

  Step 2) Copy and paste this one line, then press Enter:

    cd "/Users/developer/Downloads/ia_agent 9" && ./.venv/bin/python web_app.py

  Step 3) You should see:
            ✓ Gemini جاهز — النموذج: gemini-3.5-flash-lite
            السيرفر شغّال محلياً على: http://localhost:5050

          (We use port 5050, not the usual 5000, because macOS
           reserves port 5000 for its AirPlay Receiver service and
           it would answer with a 403 error instead of your app.)

  Step 4) Open Chrome and go to:   http://localhost:5050

  Step 5) Login screen: type any name → it opens the dashboard.
          (The login is a mockup on purpose — any input works.)

  Step 6) LEAVE THE TERMINAL WINDOW OPEN while you use the site.
          To stop the server press  Ctrl + C  in the Terminal.

  Everything works in this mode: Aura answers, manual notes are
  saved to the server, and the accept/reject/edit report buttons
  are saved too.


----------------------------------------------------------------
OPTION B — QUICK LOOK, NO SERVER
----------------------------------------------------------------

  Just double-click the file  app.html  to open it in Chrome.

  This shows the dashboard, students, statistics and the report.

  IMPORTANT LIMITATION: in this mode the page is not connected to
  any server, so these three things will NOT work:
      - Aura's chat (it will say it cannot reach the server)
      - saving a manual note on a student
      - the accept / reject / edit report buttons
  Use Option A if you need those. Printing the report works fine.

----------------------------------------------------------------
REFRESHING THE AI ANALYSIS  (app_agent.py)
----------------------------------------------------------------

  The dashboard normally uses fast built-in rules to decide who is
  red / orange / green. To have GEMINI itself write the analysis
  text ("البصيرة الذكية") for all 30 students, run:

    cd "/Users/developer/Downloads/ia_agent 9" && ./.venv/bin/python app_agent.py

  What happens: the agent analyses each student on its own — it
  fetches the records, calculates the grade trend, calculates the
  behavioral severity, checks the correlation, then submits its
  conclusion. It rewrites app.html with the results.

  ⚠ THIS TAKES ABOUT 10 MINUTES. That is normal, not a freeze.
  Your free Google plan allows only 15 requests per minute, and
  each student costs about 5 requests. The program handles this
  automatically: when it hits the limit it prints
      ⏳ حد الحصة المجانية — انتظار 32 ثانية...
  waits, and continues. Just let it run to the end.

  Run this again whenever you change the data in the CSV file.

  ⚠ IMPORTANT — WHERE THE GEMINI TEXT APPEARS:
  Running app_agent.py improves the analysis text inside app.html
  (Option B). The live server (Option A / Option C) recalculates
  the page on every visit using the fast built-in rules, so it
  shows the shorter standard recommendation text instead.
  So: if you want the professor to SEE Gemini's own written
  analysis for each student, demo with app.html (Option B), or
  ask us to connect the server to those saved results as well.
  Aura's chat always uses Gemini in every mode.


----------------------------------------------------------------
CHANGING THE STUDENT DATA
----------------------------------------------------------------

  Open  students_data_elementary.csv  (Excel or Numbers).
  Columns:
      student_id        - unique id, e.g. E131
      name              - student name
      class_name        - الصف الأول ... الصف السادس
      week              - week number 1..6
      behavior_flag     - 1 if something was noticed, otherwise 0
      behavior_category - نفسي / صحي / سلوكي  (only if flag = 1)
      behavior_note     - short description of what was noticed
      academic_score    - the grade that week, 0-100

  Save as CSV (UTF-8), then reload the page (Option A) or re-run
  app_agent.py to regenerate app.html.


----------------------------------------------------------------
CHANGING THE AI MODEL
----------------------------------------------------------------

  Open  app_agent.py  and edit the line near the top:

      LLM_MODEL = os.environ.get("GEMINI_MODEL", "gemini-3.5-flash-lite")

  Tested alternatives with your key:
      gemini-3.5-flash-lite  → current. Fast, ~4 seconds per student.
      gemini-3.5-flash       → smarter but slow, ~47 seconds per student.
      gemini-3.7-flash       → newest, sometimes returns "high demand".

  Both the analysis engine and Aura's chat use this same line.


----------------------------------------------------------------
TROUBLESHOOTING
----------------------------------------------------------------

  "command not found: python3"
      Install Python from python.org, then try again.

  "No module named flask" / "No module named google"
      You used python3 instead of ./.venv/bin/python
      Use the full command exactly as written above.

  "Address already in use" (port 5050)
      A server is already running. Close the other Terminal
      window, or press Ctrl + C in it. You can also pick another
      port:   PORT=5060 ./.venv/bin/python web_app.py

  The browser shows 403 Forbidden / an empty page
      You typed port 5000 instead of 5050. Port 5000 on macOS
      belongs to AirPlay Receiver, not to this project.

  Aura says "الحصة المجانية لهذه الدقيقة امتلأت"
      You sent too many messages in one minute (free plan limit
      is 15/minute). Wait one minute and continue.

  Aura says "مفتاح GEMINI_API_KEY غير صالح"
      The key in config.txt is wrong or expired. Get a new free
      one from aistudio.google.com and paste it into config.txt.

  Aura says "النموذج مزحوم حالياً"
      Google's servers are busy. Wait a few moments and retry.

  The dashboard opens but Aura / notes / report buttons do nothing
      You opened app.html directly (Option B). Use Option A.

  The microphone or voice does not work
      Use Google Chrome. Voice uses Chrome's built-in speech
      features and needs microphone permission.


----------------------------------------------------------------
SECURITY NOTES
----------------------------------------------------------------

  - config.txt contains your private API key. Never upload it to
    GitHub, never send it in an open WhatsApp group, and do not
    include it in the files you submit.
  - The login screen is a mockup for demonstration only. It does
    not really authenticate anyone.
  - All 30 students are fictional test data.
  - The system never gives a medical or psychological diagnosis.
    The final decision always belongs to the human specialist.

تحديث تحليل الذكاء الاصطناعي  (app_agent.py)
----------------------------------------------------------------

  الداشبورد عادةً يستخدم قواعد سريعة مدمجة عشان يحدد مين أحمر /
  برتقالي / أخضر. لو تبين Gemini نفسه يكتب نص التحليل ("البصيرة
  الذكية") لكل الـ ٣٠ طالب، شغّلي:

    cd "/Users/developer/Downloads/ia_agent 9" && ./.venv/bin/python app_agent.py

  وش يصير: الوكيل يحلل كل طالب بنفسه — يجيب سجله، يحسب اتجاه

  استنتاجه. وبالنهاية يعيد كتابة ملف app.html بالنتائج.

  ⚠ يأخذ حوالي ١٠ دقايق. هذا طبيعي، مو تعليق بالجهاز.
  الخطة المجانية من Google تسمح بـ ١٥ طلب بالدقيقة بس، وكل طالب
  يكلّف تقريباً ٥ طلبات. البرنامج يتصرف تلقائياً: لما يوصل الحد
  يطبع

  وينتظر ويكمل. خليه يكمل للآخر.

  أعيدي تشغيله كل ما تغيّرين البيانات بملف CSV.

  ⚠ مهم — وين يظهر نص Gemini؟
  تشغيل app_agent.py يحسّن نص التحليل داخل ملف app.html (الخيار ب).
  أما السيرفر (الخيار أ / ج) فيعيد حساب الصفحة مع كل زيارة بالقواعد
  السريعة المدمجة، فيعرض النص القياسي المختصر بدلاً عنه.
  يعني: لو تبين الدكتور يشوف تحليل Gemini المكتوب لكل طالب، اعرضي
  من app.html (الخيار ب)، أو اطلبي منا نربط السيرفر بنفس النتائج
  المحفوظة. شات أورا يستخدم Gemini بكل الأوضاع.
